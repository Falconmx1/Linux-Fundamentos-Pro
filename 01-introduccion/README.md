# 📘 Introducción a Linux

Bienvenido al fascinante mundo de Linux. Esta carpeta contiene los fundamentos básicos para empezar tu viaje.

---

## 🎯 Objetivos de aprendizaje

- Comprender qué es Linux y su historia
- Conocer las distribuciones más populares
- Instalar Linux (máquina virtual o dual boot)
- Familiarizarse con la terminal
- Entender la estructura del sistema de archivos
