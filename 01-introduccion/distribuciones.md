# Distribuciones de Linux

## 🎨 ¿Qué es una distribución?

Una **distribución Linux** (o "distro") es un sistema operativo completo que incluye:
- Kernel Linux
- Herramientas GNU
- Gestor de paquetes
- Entorno de escritorio (opcional)
- Software preinstalado

---

## 🏆 Principales familias

### 🔵 **Debian/Ubuntu** (Recomendada para principiantes)
- **Ubuntu**: La más popular, fácil de usar
- **Linux Mint**: Similar a Windows, muy amigable
- **Debian**: Estable y robusta

### 🔴 **Red Hat/Fedora**
- **Fedora**: Tecnologías modernas
- **RHEL**: Versión empresarial de Red Hat
- **CentOS**: Versión gratuita de RHEL

### 🟢 **Arch Linux**
- **Arch**: Personalizable al máximo
- **Manjaro**: Arch fácil de instalar
- **EndeavourOS**: Arch con instalador gráfico

### 🟡 **SUSE**
- **openSUSE**: Estable y profesional
- **SLES**: Versión empresarial

---

## 📊 Comparativa rápida

| Distro | Dificultad | Uso recomendado | Gestor de paquetes |
|--------|------------|-----------------|-------------------|
| Ubuntu | Fácil | Principiantes, servidores | apt |
| Linux Mint | Muy fácil | Ex-usuarios de Windows | apt |
| Debian | Media | Servidores estables | apt |
| Fedora | Media | Desarrolladores | dnf |
| Arch | Avanzado | Personalización | pacman |

---

## 💡 Recomendación para empezar

**Si eres nuevo**: Ubuntu o Linux Mint
**Si vienes de Windows**: Linux Mint
**Si vienes de macOS**: Ubuntu
**Si quieres aprender a fondo**: Debian o Arch
