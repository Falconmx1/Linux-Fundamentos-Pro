# Historia de Linux

## 📅 Línea del tiempo

| Año | Evento |
|-----|--------|
| 1969 | Creación de UNIX en Bell Labs |
| 1983 | Richard Stallman lanza el proyecto GNU |
| 1991 | Linus Torvalds crea el kernel Linux |
| 1992 | Linux se libera bajo GPL |
| 1993 | Nace Debian, la primera distro importante |
| 2004 | Canonical lanza Ubuntu |
| 2010s | Linux domina servidores, móviles (Android) y supercomputadoras |

## 🧠 Datos clave

- **Linus Torvalds** creó Linux a los 21 años como proyecto de hobby
- Linux es **Open Source** → cualquiera puede ver y modificar el código
- El pingüino **Tux** es la mascota oficial
- Linux está presente en el **90%+ de los servidores cloud**

## 🌍 Filosofía Linux

> "Haz una cosa y hazla bien" — Filosofía Unix

- Todo es un archivo
- Programas pequeños que se combinan
- Preferencia por archivos de texto plano
- Uso intensivo de la terminal
