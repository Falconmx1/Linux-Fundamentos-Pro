# Guía de Contribución 🤝

¡Gracias por tu interés en contribuir a **Linux Fundamentos Pro**! Toda ayuda es bienvenida, ya sea corrigiendo errores, mejorando ejemplos o añadiendo nuevo contenido.

## 📋 Cómo contribuir

### 1. Reportar errores o sugerir mejoras
- Abre un **Issue** en GitHub
- Describe claramente el problema o sugerencia
- Si es un error, incluye pasos para reproducirlo

### 2. Enviar cambios (Pull Requests)
1. **Haz un fork** del repositorio
2. **Crea una rama** para tu contribución:
